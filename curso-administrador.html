Painel de controle

Entenda todos os indicadores e como interpretar os dados do studio em tempo real.

🎙 Script

"Como administradora, a tela principal da agenda é o seu painel de gestão. Os quatro indicadores no topo — Hoje, Confirmados, Receita Prevista e Pendentes — são o pulso diário do studio. Vamos entender o que cada um significa e como agir sobre eles."

📊
O que fazer com cada indicador
1
Hoje — Total de agendamentos do dia. Compare com a capacidade máxima (número de profissionais × horas disponíveis) para saber se há espaço para mais clientes.
2
Pendentes — Se houver pendentes, priorize confirmar antes do horário. Use o botão WhatsApp para confirmar rapidamente. Meta: zero pendentes até 2h antes do horário.
3
Receita Prevista — Soma dos valores dos agendamentos confirmados. Compare com a meta diária para saber se está no ritmo certo.
💡 Rotina matinal recomendada Todo dia ao abrir o studio: 1) Verifique os Pendentes e confirme por WhatsApp. 2) Cheque os horários do dia no filtro por profissional. 3) Certifique que não há conflitos de horário. Isso leva menos de 5 minutos e evita problemas.
🗓️
Navegação avançada no calendário
1
Filtro por profissional: clique no nome de uma profissional no painel lateral para ver só os horários dela — útil para verificar disponibilidade individualmente
2
Visão semanal: navegue pelos dias com as setas ‹ › para fazer o planejamento da semana
3
Clique em qualquer dia no mini calendário para saltar diretamente para aquela data
Módulo 2 · 8 min

Gestão de usuários e acessos

Como criar, gerenciar e revogar acessos das profissionais ao sistema.

👤
Criar acesso para nova profissional
1
Acesse supabase.com/dashboard/project/tosdbnsuktdogyjardky
2
Menu esquerdo → Authentication → Users
3
Clique em "Add user" → "Create new user"
4
Preencha o e-mail e crie uma senha temporária forte (mínimo 12 caracteres)
5
Marque "Auto Confirm User" → Create User
6
Passe o e-mail e senha para a profissional — oriente a trocar a senha no primeiro acesso
💡 Boas práticas de senha Cada profissional deve ter sua própria senha, diferente da das colegas. Sugestão de formato: nome+studio+número. Ex: carol@Studio2026!
🔒
Revogar acesso de profissional
1
Supabase → Authentication → Users → encontre o usuário
2
Clique nos três pontos ⋯ ao lado do usuário → "Delete user"
3
O usuário perde o acesso imediatamente — os agendamentos dele são mantidos no banco
💆
Adicionar nova profissional ao catálogo
1
Supabase → Table Editor → tabela professionals
2
Clique em "Insert row" → preencha: nome, cargo (role), cor (formato #RRGGBB)
3
Ela aparece automaticamente no filtro lateral da agenda e no formulário de agendamento
Módulo 3 · 10 min

Relatórios e faturamento

Como extrair insights valiosos dos dados para tomar decisões melhores.

📈
O que os relatórios mostram
1
Total de agendamentos — Visão geral de movimento do studio
2
Receita total — Soma de todos os agendamentos não cancelados. Use para comparar períodos.
3
Agendamentos por profissional — Veja quem está com mais demanda para equilibrar a carga
4
Serviços mais agendados — Descubra quais serviços são campeões de demanda
💡 Insights acionáveis dos relatórios Se um serviço aparece muito nos relatórios (ex: manicure), avalie aumentar a capacidade ou o preço. Se um serviço tem pouca demanda (ex: peeling), crie uma promoção no Instagram. Os dados guiam as decisões!
⚡ Consultas avançadas via Supabase

Para relatórios mais detalhados (por mês, por período, por cliente VIP), acesse o SQL Editor do Supabase e use consultas como:

SELECT services.name, COUNT(*) as total, SUM(price) as receita FROM appointments JOIN services ON appointments.service_id = services.id WHERE status != 'cancelled' GROUP BY services.name ORDER BY total DESC;

Isso retorna uma tabela com cada serviço, quantas vezes foi feito e a receita total de cada um.

📅
Relatório mensal — rotina recomendada
✓
Verificar receita total do mês vs meta
✓
Ver serviço mais agendado e avaliar preço
✓
Identificar profissional com menor demanda e escalar divulgação
✓
Exportar dados do Supabase como backup (.csv)
✓
Verificar custo da API Anthropic (console.anthropic.com → Billing)
Módulo 4 · 10 min

Automações com WhatsApp

Como automatizar confirmações, lembretes e reativação de clientes para economizar tempo.

🎙 Script

"Uma das maiores oportunidades de economia de tempo está na comunicação com clientes. Atualmente a agenda já tem botões de WhatsApp integrados — mas podemos ir muito além com automação de mensagens em momentos estratégicos. Vamos ver como implementar isso passo a passo."

✅
Confirmação automática — JÁ DISPONÍVEL
Ao criar um agendamento, clique no botão WhatsApp verde. Uma mensagem completa com todos os dados é gerada e enviada para a cliente em 2 cliques.
✓ Já funciona
🔔
Lembrete 24h antes — Manual com IA
Use o Assistente IA: "Crie uma mensagem de lembrete para a Amanda Costa, amanhã às 14h, serviço de coloração". Copie e envie pelo WhatsApp da agenda.
✓ Já funciona
💤
Reativação de clientes inativos — Via IA
No Assistente IA, pergunte: "Quais clientes não vêm há mais de 60 dias?". Ele lista e você pode pedir: "Crie mensagem de reativação para cada uma delas".
✓ Já funciona
⚡
Envio automático sem clique — Evolution API
Com a Evolution API (servidor VPS ~R$50/mês), as mensagens são enviadas automaticamente sem nenhuma interação humana. Confirmação ao agendar, lembrete 24h antes, follow-up após o atendimento.
⚙️ Requer configuração técnica
📅
Google Calendar sync
Sincronizar agendamentos com o Google Calendar via Supabase webhooks. Cada agendamento aparece automaticamente no calendário do celular da Sônia.
⚙️ Requer configuração
📊
Relatório semanal automático por WhatsApp
Via n8n (automação gratuita self-hosted): toda segunda-feira às 8h, um resumo da semana anterior chega no WhatsApp da Sônia automaticamente.
🔧 Avançado
💡 Por onde começar com automações Comece pelas que já funcionam (confirmação + lembrete via IA). Quando o volume crescer e justificar o custo, implemente a Evolution API. O Google Calendar sync pode ser feito a qualquer momento.

Módulo 6 · 8 min

Manutenção e atualizações

Como manter o sistema funcionando, atualizado e seguro.

🔄
Como atualizar o sistema
1
Qualquer alteração (novo serviço, novo preço, novo texto) é feita em github.com/hamilton66/studio-agenda
2
Clique no arquivo a editar → lápis ✏️ → faça a alteração → Commit changes
3
O Vercel detecta a mudança e publica automaticamente em ~1 minuto. Nenhuma ação adicional necessária.
💰
Atualizar preços e serviços
1
Supabase → Table Editor → tabela services
2
Clique na linha do serviço que deseja editar
3
Altere o valor no campo price ou duration_min → Enter para salvar
4
A alteração reflete instantaneamente na agenda — sem precisar de deploy!
🛡️
Checklist de segurança mensal
✓
Verificar se todos os usuários ativos ainda fazem parte da equipe
✓
Checar saldo/custo da API Anthropic em console.anthropic.com
✓
Exportar backup dos dados do Supabase (Table Editor → Export CSV)
✓
Verificar se o Vercel está com status "Ready" em todos os deploys
✓
Trocar senha do GitHub hamilton66 (antes de 16/06/2026 — alerta ativo)
⚡ Solução de problemas rápidos

Site não carrega: Vercel → projeto studio-agenda → Deployments → verificar status do último deploy

IA não responde: console.anthropic.com → verificar saldo e se a chave studio-agenda está ativa

Dados não aparecem: Supabase → Logs → verificar se há erros de conexão

Login não funciona: Supabase → Authentication → Users → verificar se o usuário existe e está confirmado
