Usuários e acessos

Como criar, gerenciar e revogar acessos das profissionais ao sistema.

👤
Criar acesso para nova profissional
1

Acesse supabase.com/dashboard/project/tosdbnsuktdogyjardky

2

Menu esquerdo → Authentication → Users

3

Clique em "Add user" → "Create new user"

4

Preencha o e-mail e crie uma senha temporária forte (mínimo 12 caracteres)

5

Marque "Auto Confirm User" → Create User

6

Passe o e-mail e senha para a profissional e oriente a trocar no primeiro acesso

🔒
Revogar acesso
1

Supabase → Authentication → Users → encontre o usuário

2

Clique nos três pontos ⋯ → "Delete user"

3

Acesso revogado imediatamente — agendamentos são mantidos

💆
Adicionar nova profissional ao catálogo
1

Supabase → Table Editor → tabela professionals

2

Clique em "Insert row" → preencha nome, cargo e cor (formato #RRGGBB)

3

Ela aparece automaticamente no filtro e no formulário de agendamento

💡 Boas práticas de senhaCada profissional deve ter sua própria senha. Sugestão: nome+studio+número. Ex: carol@Studio2026!

Relatórios e faturamento

Como extrair insights dos dados para tomar melhores decisões.

🎙 Script para áudio

"Os relatórios são onde os dados viram decisões. Vamos explorar cada indicador e como usar as informações para melhorar o negócio do studio."

📈
O que os relatórios mostram
1

Total de agendamentos — visão geral do movimento

2

Receita total — soma de todos não cancelados. Compare períodos para ver crescimento.

3

Por profissional — quem está com mais demanda para equilibrar carga

4

Serviços mais agendados — descubra os campeões de demanda

💡 Insights acionáveisServiço muito demandado? Avalie aumentar o preço. Pouca demanda? Crie promoção no Instagram. Profissional com menos horários? Escale a divulgação. Os dados guiam as decisões!
⚡ Consulta avançada via Supabase SQL Editor

Para relatórios por período, acesse o SQL Editor do Supabase e execute:

SELECT services.name, COUNT(*) as total, SUM(price) as receita FROM appointments JOIN services ON appointments.service_id = services.id WHERE status != 'cancelled' GROUP BY services.name ORDER BY total DESC;

Retorna cada serviço, quantas vezes foi feito e a receita total de cada um.

Checklist de relatório mensal
✓

✓
Ver serviço mais agendado e avaliar preço
✓
Identificar profissional com menor demanda
✓
Exportar dados do Supabase como backup (.csv)
✓
Verificar custo da API Anthropic (console.anthropic.com → Billing)

Automações com WhatsApp

Como automatizar confirmações, lembretes e reativação de clientes.

✅
Confirmação automática — JÁ DISPONÍVEL
Ao criar um agendamento, clique no botão WhatsApp verde. Mensagem completa gerada e enviada em 2 cliques.
✓ Já funciona
🔔
Lembrete 24h — Via Assistente IA
Peça ao Assistente IA: "Crie mensagem de lembrete para a Amanda, amanhã às 14h, coloração". Copie e envie pelo WhatsApp.
✓ Já funciona
💤
Reativação de clientes inativos — Via IA
No Assistente IA: "Quais clientes não vêm há mais de 60 dias?" → "Crie mensagem de reativação para cada uma".
✓ Já funciona
⚡
Envio automático sem clique — Evolution API
Com Evolution API (VPS ~R$50/mês), mensagens são enviadas automaticamente: confirmação ao agendar, lembrete 24h antes, follow-up após atendimento.
⚙️ Requer configuração técnica
📅
Google Calendar sync
Sincronizar agendamentos com Google Calendar via Supabase webhooks. Cada agendamento aparece no calendário do celular.
⚙️ Requer configuração
📊
Relatório semanal automático por WhatsApp
Via n8n (gratuito self-hosted): toda segunda-feira às 8h, resumo da semana chega no seu WhatsApp automaticamente.
🔧 Avançado
💡 Por onde começarComece pelas que já funcionam (confirmação + lembrete via IA). Quando o volume crescer e justificar, implemente a Evolution API. Google Calendar pode ser feito a qualquer momento.

Manutenção e segurança

Como manter o sistema funcionando, atualizado e seguro.

🔄
Como atualizar o sistema
1

Acesse github.com/hamilton66/studio-agenda

2

Clique no arquivo → lápis ✏️ → faça a alteração → Commit changes

3

Vercel publica automaticamente em ~1 minuto. Nenhuma ação adicional.

💰
Atualizar preços e serviços
1

Supabase → Table Editor → tabela services

2

Clique na linha do serviço → altere o campo price ou duration_min → Enter

3

Atualiza instantaneamente na agenda — sem deploy!

🛡️
Checklist de segurança mensal
✓
Verificar se todos os usuários ativos ainda fazem parte da equipe
✓
Checar custo da API Anthropic em console.anthropic.com
✓
Exportar backup dos dados (Supabase → Table Editor → Export CSV)
✓
Verificar status "Ready" no Vercel dashboard
✓
⚠️ Trocar senha do GitHub hamilton66 antes de 16/06/2026
Solução rápida de problemas

Site não carrega: Vercel → studio-agenda → Deployments → verificar último deploy

IA não responde: console.anthropic.com → verificar saldo e chave studio-agenda

Dados não aparecem: Supabase → Logs → verificar erros de conexão

Login não funciona: Supabase → Authentication → Users → verificar usuário
